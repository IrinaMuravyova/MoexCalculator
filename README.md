Основной экран приложения — поля ввода и отображения валютных сумм с флагами стран-эмитентов и кодами валют. 
Нажатие на флаг или код валюты открывает в нижней части экрана селектор валют. 
В нём список валют слева соответствует верхнему полю ввода, а справа — нижнему. 
Если изменить в нём тип валюты — флаг и код валюты меняются автоматически. 
При вводе валютной суммы в верхнее или нижнее поле валютная сумма в другом поле пересчитывается автоматически.

Его мы построим на основе паттерна MVVM с использованием SwiftUI и Combine.
Курсы валют приложение будет брать с сайта МосБиржи с помощью сетевого запроса. 
Полученные данные нужно декодировать и сохранить в модели данных. 
При загрузке данных приложение должно уметь работать с различными состояниями:
«Данные загружаются»,
«Данные загружены»,
«Ошибка при загрузке данных».
